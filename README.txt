PhoneSmith — 3D smartphone customization workshop

Files (all in this one folder, no subfolders):
  index.html          the page — open this
  style.css           styles
  app.js              the workshop: 3D scene, parts, dragging, export
  three.min.js        three.js r128 (3D engine, MIT licence)
  OrbitControls.js    three.js camera orbit controls
  THREE-LICENSE.txt   three.js licence

Run it
  Double-click index.html, or upload the whole folder to any static host
  (GitHub Pages, Neocities, Netlify). It needs no server or build step.
  Fonts load from Google Fonts when online; offline it falls back to system fonts.

Your build is saved in the browser automatically. "Render image" then
"Save PNG" downloads the render.
